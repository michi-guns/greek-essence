# A-001: Quotes Normally Precede Bookings

## Status

Unverified

## Assumption

A booking is normally created from an accepted quote.

## Evidence

The planned workflow treats quotations as the commercial proposal before
booking confirmation.

## Questions

- Can staff create bookings directly?
- Can an accepted quote be edited?
- Is acceptance formally recorded?

## Impact

Affects quote lifecycle, booking creation, audit history, and navigation.
