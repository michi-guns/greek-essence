# Security Baseline

- Authenticate every protected operation.
- Authorize every mutation server-side.
- Validate all untrusted input.
- Keep secrets server-only.
- Use least-privilege Sanity tokens.
- Verify webhook secrets or signatures.
- Do not log sensitive traveler or payment data.
- Do not store raw card details.
- Protect private documents and generated files.
- Record actor and timestamp for sensitive business changes.
- Treat uploaded files and filenames as untrusted.
- Minimize retained identity and passport information.

Flag legal, tax, invoicing, payment, and personal-data assumptions for human
review.
