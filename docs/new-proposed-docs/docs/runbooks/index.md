# Runbooks

Runbooks are action-oriented procedures for incidents and repeated operational
tasks.

## Available runbooks

- [Sanity webhook failure](./sanity-webhook-failure.md)
- [Failed database migration](./failed-database-migration.md)

Use [`template.md`](./template.md) when adding a runbook.

Add runbooks from real incidents or repeated needs. Do not create speculative
procedures without an owner or operational value.
