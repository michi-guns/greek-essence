# A-002: Customers and Travelers Are Separate Concepts

## Status

Partially verified

## Assumption

The person or organization paying may differ from the people traveling.

## Evidence

Common cases include parents booking for children, companies booking for
employees, and one person booking for a group.

## Questions

- Can one traveler belong to several customers?
- Which traveler details must be retained?
- Can a traveler later become a customer?

## Impact

Affects data modeling, forms, permissions, privacy, and booking relationships.
