## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. Where it lives: app/directions/ - index page, three route folders (type-led, image-led, editorial-grid), shared _shared/ (content.ts with the one content set, demo-bar.tsx, directions.css scoped per direction by a root class). No files in components/ (throwaway, one caller each; DS-002). Removed by GE-005.01 once the chosen direction is rebuilt as the Home comp; that task gets an AC to delete app/directions/.
2. Guard: app/directions/layout.tsx sets robots noindex and calls notFound() when process.env.CONTEXT === 'production' (Netlify build env), so the routes 404 on release even if the delete is late.
3. Fonts: the directions layout imports @fontsource-variable/fraunces/full.css and full-italic.css (opsz, SOFT, true italic) per §4.1; comps set their own CSS per §4 note (globals.css tokens are not yet audited). Display weight 300-400, radius 0, no card border/fill/shadow.
4. Photos: 6-7 free Unsplash photos per §4.3 (warm, muted, architecture/texture/food/detail, no identifiable people), found via Chrome, hotlinked through next/image and the existing custom loader (images.unsplash.com is imgix and accepts the same w/q/auto/fit params). No binaries in the repo. Logged in content.ts and in the report (source URL, author, licence).
5. Content (same in all three): header (Menu, wordmark, Plan your trip), roman+italic headline, serif lede, three sample packages (place, dek, days as labelled placeholders), one action. No prices (D-006), no invented claims. Copy drafted (D-035).
6. Build per §4.6: type-led (72-80px Fraunces, italic second line, inset photo below; lede then one image at a time), image-led (full-bleed photo with wordmark and one outline button, small headline bottom-left; offset photo cluster with captions), editorial grid (headline+dek left, tall photo right, hairline under header, packages start in the fold; numbered (01) index in 3 columns). Motion per DS-006 in CSS only: hover colour/underline 220ms, card image 1.03 over 700ms, hero settle 1.04->1 and italic line fade 150ms after. Scroll reveal is left out (needs public/motion.js, a later task) - stated in the report.
7. Screenshot loop at 390/768/1024/1440 via Playwright against pnpm build + start; max three loops per direction. Measure §4.8 numbers with the existing .local/design-exploration/tools helpers.
8. One e2e spec: each direction route has one h1 and no horizontal overflow at 320 and 390. Deleted with the directions.
9. Gates: pnpm check, pnpm build, the e2e spec. A-007 evidence into .local/evidence/2026-09-23-first-fold-directions/.
10. Independent review: visual-reviewer + code-reviewer in parallel (09-REVIEW), max three rounds.
11. Report: local HTML side-by-side in .local/design-exploration/2026-09-23-first-fold-directions/, screenshots inlined, one recommendation, one question to the operator (GE-003.04).
12. doc-lifecycle, merge task branch into phase/01.1-direction, push.
