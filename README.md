# Greek Essence

Marketing and enquiry site for a boutique Greece travel-planning agency.

**Start here:** [`docs/v1/README.md`](docs/v1/README.md) — decisions, scope, design system,
workflow, stack and architecture. Tasks live in [`backlog/`](backlog/) (Backlog.md CLI).

```bash
pnpm install
pnpm dev
```

Requires Node 24+ and pnpm 11+. Copy `.env.example` to `.env.local` before running.

The previous prototype and its documentation are preserved on the `archive/v0-preview` branch.
