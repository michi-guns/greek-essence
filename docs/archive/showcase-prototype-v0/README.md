# Showcase Prototype v0 Documentation Archive

## Status

Archived by the operator on 2026-07-29. Everything below this directory is
historical reference and is **not authoritative** for the current product,
architecture, design, tooling, scope, or implementation.

This archive includes the former:

- project protocol;
- product requirements;
- prototype specification;
- technical design;
- design system;
- agent-tooling documentation; and
- curated prototype reference material.

Statements inside those documents that describe themselves or another archived
document as approved, binding, current, or authoritative apply only to the old
showcase-prototype baseline. They do not override current repository guidance.

## Why It Was Archived

The project is being rebaselined around a public, production-facing preview
that is expected to receive real visitors and enquiries. Material new product
requirements and candidate CMS, persistence, and backend responsibilities make
the old static-first showcase assumptions unsuitable as the starting contract.

## Permitted Use

Use this material to recover history, identify lessons, understand earlier
language and intent, or gather visual and implementation inspiration. Revalidate
anything worth carrying forward through the active grilling process before it
becomes a current decision or requirement.

Do not use this archive to:

- authorize implementation or dependency choices;
- infer that an old approval remains in force;
- assume the product must remain static-first or local-JSON based;
- rule out a CMS, database, ORM, backend, authenticated workflow, or operational
  capability; or
- silently restore old scope, workflows, terminology, quality gates, or
  architecture.
